# Pixel Collage Lite

一个轻量的“极简解构拼贴”工具：云端生成主体 mask，浏览器 Canvas 完成裁切、撕纸贴纸、自动排版和 PNG 导出。

> **项目来源说明**：本项目由大模型辅助开发，不是纯原创；构思和实现参考了多个 GitHub 开源项目的思路。当前仓库的初始资料没有附上完整的上游项目清单，因此这里不猜测或虚构项目名称、作者及许可证。发布者应在确认具体来源后，在下方补充项目链接、借鉴内容和各自许可证；若实际复用了代码或素材，还应按对应许可证履行署名及分发义务。

## 工作方式

1. 浏览器将上传图片缩放后发送到本项目服务端。
2. 服务端以异步任务方式调用 Replicate 上的 SAM 2 分割模型，前端轮询任务状态。
3. 浏览器筛选 mask，使用 Canvas 进行构图和拼贴。
4. PNG 结果直接在浏览器生成并下载。

本项目没有在本机运行模型权重。图片会发送到你配置的 Replicate 服务，服务可用性、处理时间和费用由 Replicate 账户及服务状态决定。

## 本地运行

需要 Node.js 18 或更高版本。项目没有 Python、PyTorch 或前端框架。

```bash
cp .env.example .env
```

编辑 `.env` 并填入自己的 Replicate Token，然后启动：

```bash
npm start
```

浏览器访问 <http://127.0.0.1:8787>。Token 只由服务端读取，不会发送给前端。

## 部署到 Vercel

将 GitHub 仓库导入 Vercel，并在项目环境变量中设置：

- `REPLICATE_API_TOKEN`：必填，Replicate API Token。
- `REPLICATE_MODEL_VERSION`：可选，模型版本；未设置时使用 `.env.example` 中的默认值。

`api/collage.js` 和 `api/health.js` 是 Serverless API 入口。任务提交后立即返回 ID，前端通过后续请求获取状态和结果，避免长时间占用单次函数调用。

### 公开部署注意事项

接口对每个客户端 IP 做每分钟最多 5 次新任务的进程内限流，并校验图片数据格式和任务 ID。这是基础防护，不是强身份认证：Serverless 实例可能彼此独立或重启，进程内计数不能作为可靠的全局额度保护。公开部署前，应在 CDN/WAF 或共享存储限流服务中再配置持久化限流与额度告警，并按实际用户规模调整策略。不要把 Replicate Token 放入前端。

## 已知边界

- 自动 mask 依赖云端 SAM 2；当前按面积、尺寸和框重叠做几何筛选，没有语义类别标签。
- 不同图片的主体数量和分割质量会有差异；主体过小、背景复杂或遮挡严重时，建议换更清晰的图片。
- 布局会尽量把贴纸限制在画布内，但主体比例极端或主体过多时，视觉效果仍可能需要调整。
